Every finding lists source ids. This is what each id points to. They're the laws and official guidance, not blog posts.

**Status: links added 2026-11-13 and not yet re-verified by a lawyer.** Before each release, check that the links still resolve and the rules haven't changed, then update the date. Laws change: the FTC's 2024 "Click-to-Cancel" rule was struck down in 2025, so this skill relies on ROSCA and state auto-renewal laws instead.
